# To-Do Application
This Python application is a simple command-line based To-Do list manager. It allows users to add, delete, view, and quit tasks using specific commands.

Features
•	Add Task: Users can add a new task to the list.
•	Delete Task: Users can delete a task by specifying its index.
•	View Tasks: Users can view all tasks currently in the list.
•	Quit: Users can exit the application.

 Commands
  •	ADD or 1: Adds a task to the task list.
  •	DELETE or 2: Deletes a task from the task list by index.
  •	VIEW or 3: Displays all tasks with their indices.
  •	QUIT or 4: Exits the application.
  
 How to Use
  1.	Run the application.
  2.	Follow the prompts to enter commands.
  3.	Use the command names or their corresponding numbers to perform actions.
  4.	To delete a task, enter the index of the task you wish to remove.
  5.	Type QUIT or 4 to exit the application.
     
Error Handling
  •	If an invalid command is entered, the application will prompt the user to try again.
  •	When deleting a task, if an invalid index is entered, the application will request a valid index.
  
Notes
  •	The application will print a goodbye message upon exiting.
  •	All tasks are stored in a list and are lost when the application is closed.
